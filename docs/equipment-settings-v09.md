# 0.9.0 器材設定

啞鈴臥推新增「平躺 0°／上斜 30°」兩個已校正角度。三十度配置使用獨立的實體椅背與座墊，頭、上背、啞鈴與手部一起改成對應的姿勢；雙腳保留地面目標，腿部仍由固定骨長的 IK 求解。拿鈴、坐下、大腿支撐、後靠、推舉、起身和放回都走完整流程。沒有提供任意角度滑桿。

三頭下壓新增直桿配置。直桿是半徑 16 mm、長 80 cm 的實體物件，雙手正握、握距固定。準備流程為站穩、抬手、對準、閉握、提離掛位、退半步，再開始伸肘；結束時倒序放回並放手。手指張開時先在桿前保留空間，關握時平順靠近；不是把手掌碰撞整段豁免。循環的桿路徑位於大腿前方，沒有沿用繩索分向身側的軌跡。

其他握把選單整理現有已校正的組合：直桿／EZ 桿彎舉，以及單手 D 把／雙手 V 把划船。選項會指出對應動作，不會把同一個持握動畫套到任意附件。兩種新配置沿用原動作 ID 和學習進度，清單仍為 70 項、可記錄的動作與團課仍為 62 項。

設定只在未使用器材時套用。使用中變更時，由主程式先走完回位、放手與離開，再套用並重新就位；底層 API 也會拒絕正在準備或持握時的實際設定變更。換配置會先隱藏上一組實體，重複切換不會堆出多張椅子、托盤或握把。

新配置的最大骨架目標偏差分別約 3.92 mm（臥推）與 5.82 mm（直桿），出現在走近或離開的步行階段，低於既有 15 mm 容許值；沒有把所有姿勢宣稱成完全零誤差。

[握持方向實量](../artifacts/v09-equipment-hand-frames.json)確認，直桿循環的兩手掌法向 Y 均朝下（約 −0.993～−0.655），不是只把反握動作改成「正握」名稱；閉握時最大腕偏折約 13.69°。另外量到一項既有動作限制：臥推拿鈴轉成身側持握的中途，腕偏折最高約 49.56°，發生在進入相位 0.47667、尚未坐下與調整椅背的階段；平躺和上斜配置在此姿勢完全相同。這次依保留原動作的範圍保留該過渡，沒有宣稱整段手腕都保持中立；後續自然度與負重教學適用性仍需一起複核。

## 看圖與限制

`node scripts/review-equipment-settings-v09.mjs` 會透過真正的網頁活動介面，擷取兩種新配置的進入、循環和離開：正、側、背共 54 個畫格，另有兩種配置的四張握持近景。數值檢查不取代實際開圖或真人教練審核，靜態關鍵格也不等於連續影片驗收。

正式十張 PNG 已逐張實際開圖檢視，見[拍攝報告](../artifacts/equipment-settings-review-v09/capture-report.json)及[看圖紀錄](../artifacts/equipment-settings-review-v09/visual-review.json)。所看角度未確認新的明顯穿插；椅背角度、大腿支撐、逐段後靠，以及直桿的張手／正握／退半步和大腿前方行程可辨認。托架、椅背、槓片和桿身會遮住部分表面，沒有把遮住的掌心、指尖或背部當成已目視通過。

本版仍是固定比例模型、既定器材尺寸和有限的校正配置。換模型或新增角度／握把，需要重新檢查姿勢、骨長、支撐、拿放及金屬表面。沒有加入真人動作捕捉，也沒有冒稱已取得教練簽核。
