# 第一批真人教練複核資料

已備妥[可離線閱讀的審查包](../artifacts/coach-review-v015/ready-pack/review.html)，以及可匯回工作台的[JSON 圖包](../artifacts/coach-review-v015/ready-pack/review.json)。包內沒有填表人姓名或意見，65 項動作／課程全部維持待審，沒有替真人教練簽核。

這批先拍六個優先項目：啞鈴肩推、杯式深蹲、啞鈴臥推、自由槓深蹲、槓片腿推與健身車。每項取就位 35%、運動 50%、離開 65%，各有正、側、背面，合計 54 次真實 GLB 擷取。進出採對稱路徑，這組取樣的就位 35% 與離開 65% 圖像相同；54 次擷取只有 36 個不同圖像雜湊，不把它們算成 54 個不同姿勢。

這些是靜態複核素材，不能代替看完整連續動作。其餘 59 項尚未補本版三向圖，可以直接在遊戲工作台操作並下載。手掌內側、踏板或靠墊遮住的位置，需要換角度、慢放與現場教練確認，不能用看不到就當作通過。

## 建議先看的問題

- 健身車跨車時的抬膝、抬肘與張手過渡，請看連續速度與是否符合實際上車習慣。這批圖沒有被當成自然度已通過。
- 肩推與杯式深蹲只採用真人動捕的時間比例，手腳仍沿已校正的骨架與器材路徑；杯式的原始深蹲素材未持啞鈴。
- 臥推的坐穩、後躺與放回，自由槓的進出架，以及腿推的起身與跨架，請核對支撐、重心轉移、腕角及手腳放置順序。
- 文字中的呼吸、活動範圍、常見錯誤和新手適用性，需教練逐項留意；本輪幾何與程式通過不等於教學已獲審核。

教練可在「操作說明 → 動作檢查與問題紀錄」匯入 JSON，逐項記錄意見，再匯出 JSON／HTML／CSV。資格欄為自填資料，工具不據此自動認證。圖包只含畫面、接點與版本，沒有讀取私人帳號或訓練日誌。
