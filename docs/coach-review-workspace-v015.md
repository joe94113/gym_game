# 真人教練審查交付

使用者目前尚未提供合作教練，因此這版完成可交接的工具與資料，沒有填入真人簽核。填表人寫下姓名、資格或「可接受」，都只是自填意見，不會自動取得專業認證。

## 怎麼交給教練

1. 在遊戲選好動作，等人物完成就位，再開啟「操作說明 → 動作檢查與問題紀錄」。工作台會暫停原動作，關閉後還原原先位置與播放狀態。
2. 選「就位與拿取、運動行程、放回與離開」及行程位置，實際拍正面、側面、背面。九格只列已拍的畫面和當時百分比；沒有圖片的格子保持「尚未拍攝」。每格保留最後一次拍攝，不代表整段動畫都已看完。
3. 填寫問題、實際填表人及自填身分，選「尚待審查、需要修正、填表人認為可接受」。不必先填教練姓名，也沒有預填證照。
4. 匯出 **JSON** 留完整圖片與資料，再匯出 **離線 HTML 審查包** 交給教練。HTML 是單一檔案，可離線看圖片、65 項狀態、各筆意見、來源版本及參考連結；外部教學來源需要網路。
5. 教練可在工作台開啟相同動作、匯入 JSON，再補看連續動作與問題位置、寫下意見並重新匯出。CSV 另提供純文字意見，方便整理。

HTML 與 JSON 會包含自填姓名、身分與意見及實際畫面；功能不讀取帳號、密碼或訓練日誌。檔案應交給實際審查人，不是公開展示的完成證明。

## 圖片與瀏覽器空間

多角度圖只保留在目前頁面的記憶體。瀏覽器跨次保存文字及最後一張紀錄附圖，避免數十張 PNG 塞滿 localStorage。重新整理或關閉分頁前，請下載 JSON；HTML 供閱讀，不能匯回成工作台資料。

一份 JSON 上限 16 MB、500 筆意見及 100 張實際證據。每張圖上限 1 MB、1024 × 1024 px。超過時會停止該次加入，原資料保留；可先下載現有包，再分批整理。工作台拍攝為 480 × 480 px。

## 版本、匯入與狀態

- v3 審查包保存來源版本、意見、圖片與實際相位。格式只接受已支援的版本、目前 65 個動作 ID，以及有效階段和 PNG。
- 舊 v2 檔案可匯入，但原本沒有精確版號的紀錄會標成 `legacy-v013-unversioned`。舊版的「已複核」不會變成當前版本「可接受」。不同版本的可接受意見也不會直接算作本版已審。
- 重複紀錄會略過；較舊意見不會掩蓋日期較新的意見。圖片依實際拍攝日期保留各格較新的一張。
- 匯入先整包驗證，再合併。未知動作、越界相位、損壞 PNG、偽造專業簽核或過量資料，會指出欄位並保留原資料。
- 「尚待審查」包含完全沒有意見的項目。沒有拍照、沒有填意見，或只有舊版意見，都不能推算成通過。

## 這次可交付的空白資料

[離線審查清單](coach-review-handoff-v015.html)與[空白工作台 JSON](coach-review-handoff-v015.json)列出目前 65 個動作及來源，所有項目維持尚待審查、沒有假圖片或教練姓名。實際拍攝的圖與問題，需由工作台匯出後再交接。

完整流程請由教練連續觀看。靜態圖和數值可協助指出手腕、肩肘髖膝踝、掌心握持、鞋底支撐、靠墊接觸、軀幹與器材碰撞的位置，不能代替動作自然度、負重與個別適用性的專業判斷。
