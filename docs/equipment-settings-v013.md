# 0.13 器材調整與實體對位

這次把器材設定接到實際座墊、握把、滑輪、纜線、配重插銷與槓片。人物保留原模型及骨長，依新的接點重新求解手腳。設定範圍按機型列出，沒有把尚未校正的機台也顯示成可自由調整。

| 器材／動作 | 可調整內容 |
| --- | --- |
| 胸推機、肩推機 | 座墊 62～66 cm，每次 1 cm；插銷配重 5～55 kg，每次 5 kg |
| 高位下拉機 | 座墊 62～66 cm；握距 76～84 cm，每次 2 cm；插銷配重 5～55 kg |
| 腿伸展機 | 座墊 69～73 cm；插銷配重 5～55 kg。座墊、膝關節轉軸、握把和腳部接點一起升降 |
| 坐姿划船、腿彎舉、蝴蝶夾胸、側平舉機 | 插銷配重 5～55 kg |
| 站姿滑輪夾胸 | 雙側滑輪 156～176 cm，每次 5 cm；插銷配重 5～55 kg |
| 11 種龍門架動作 | 各自相容的滑輪高度區間，每次 5 cm；插銷配重 5～55 kg |
| 基本及追加槓片器材 | 每側 0～40 kg，每次 1.25 kg；左右實體掛片同步，包含平躺／下斜胸推及牧師彎舉 |

原有啞鈴臥推椅背 0～45°、每次 1°，以及繩索／直桿、直桿／EZ 桿、D 把／V 把的相容動作選擇保留。反向飛鳥目前未開放新增設定；它與蝴蝶夾胸共用互動點，介面依實際選到的活動判斷，避免調到未顯示的機構。

## 實際會改變什麼

- 座墊上升時，臀部與上身一起上升。胸推、肩推及下拉的腳仍踩在地面；腿伸展的膝軸、腿部接點、握把與可動滾筒一起升降。準備用的姿勢重新取樣，下一次進入不會沿用舊座高。
- 下拉握距會更新兩支真正的握把及掌心目標，不靠拉長手臂接到握把。
- 滑輪高度更新實際輪軸與主纜線的固定端。各動作保留原本的拉力方向範圍與相容握把，不開放任意組合。
- 插銷移到所選配重片；原有插銷機只有選中的上層配重隨機構抬升，下方未選的片留在底座。11 片用一個 `InstancedMesh` 繪製。龍門架罩殼上的實體選重插銷也會移到所選位置。
- 槓片以 1.25／2.5／5／10／20 kg 拆載，總重量在左右各自加總核對。原每側 20 kg 保留兩片 10 kg，40 kg 使用兩片 20 kg，避免把掛片不必要地排得過長。0 kg 會留下空掛桿。微型槓片採較小半徑，片與片之間保留實體厚度。

所有重量都是遊戲中的器材配置，沒有據此推算玩家適合使用的公斤數，也沒有新增通用剛體／肌肉受力物理。

## 介面與執行介面

`equipmentOptionsFor(id).adjustments` 回傳 `{key,label,unit,min,max,step,defaultValue,help}`。設定鍵為 `seatHeightCm`、`gripWidthCm`、`pulleyHeightCm`、`weightKg`、`plateLoadKg`。定義集中在 [equipment-calibration-v013.js](../src/equipment-calibration-v013.js)。

普通器材及追加機台提供 `getEquipmentOptions(id)`、`getEquipmentSettings(id)`、`setEquipmentSettings(patch,id)`。Rig 沿用原本介面，接受部分更新，回傳 `{ok,changed,settings,reason?}`；不在已校正範圍、不是指定步進、非數值及未知欄位都拒絕，原設定保留。

世界執行介面應先讓人物放回、放手並完成離場，再套用設定及重建進出路徑，最後重新就位。仍在使用器材時不直接改動手中的設備。反覆切換滑輪高度時會移除上一份進出路徑自行建立的托架、扣環與碰撞資料，避免重複堆出道具。

## 驗證

[八項新增 Node 測試](../tests/equipment-calibration-v013.test.mjs)檢查實體座墊與姿勢、腿伸展連桿、握距、選中／未選配重片、左右拆片重量、真正主纜線端點、使用中拒絕，以及反覆切換不增加道具；原有五項設定測試保留。舊的繩索設定預期值加入新增的高度與配重欄位，原有 handle 值仍維持。

```powershell
node --test tests/equipment-calibration-v013.test.mjs tests/equipment-settings.test.mjs
node scripts/qualify-equipment-settings-v013.mjs
node scripts/qualify-equipment-lifecycles-v013.mjs
```

正式數值報告分為[運動循環](../artifacts/equipment-settings-v013/qualification.json)及[完整進出](../artifacts/equipment-settings-v013/lifecycles-qualification.json)。檢查實際 GLB 的固定骨長與手腳可達、身體對器材、自身碰撞及定期的變形後蒙皮樣本；涵蓋設定端點、下拉座高／握距四個角落，以及槓片片數較多的 38.75 kg。快測輸出另存 pilot，不能代替正式報告。來源 SHA 與量測期間的變動會寫入報告。

最後來源凍結後已重跑 **152 組配置**：循環取樣 **15,352 個姿勢**，完整進入與離開取樣 **30,704 個姿勢**，兩份正式報告均通過。文件更新時逐一核對兩份報告中的來源 SHA，與目前檔案一致，`changedSources` 皆為空。兩份報告已對應最後的來源，包含腿推準備路徑與升降座墊修正；七種啞鈴握桿動作的手指另外由[握桿與放手驗證](dumbbell-fingers-v013.md)檢查。

初次快測確實抓到升高座墊的腿伸展準備會撞膝前滾筒，以及提踵經過較多掛片時手部相撞。修正採調整準備站腳、繞行及合理拆片，沒有增加大腿／手臂的接觸豁免，也沒有把碰撞體縮成看不到問題。上述最後正式重跑已包含這些修正。

這些是固定人物、有限配置與姿勢的數值檢查。連續動作的外觀、器材遮擋、手指與教學適用性仍需另看實際網頁與真人審查，不能把通過取樣寫成任意姿勢都沒有穿模。
