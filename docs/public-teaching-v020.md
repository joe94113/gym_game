# 肌動基地 0.20：公開教學與原廠說明對照

更新日期：2026-11-03。

目前依公開教學與原廠說明核對動作。遊戲教學面板及[文字指南](https://joe94113.github.io/gym_game/guide/)共用逐項來源資料，可以查看來源類型、核對日期、已核對的部分與未涵蓋內容。真人專業審查尚未執行；日後有合作教練時，可在既有工作台另外留下實際意見與身分紀錄，工具本身不會核發專業認證。

這次沒有新增全身動捕，也沒有把讀過教學當成逐影格動畫驗收。人物動作的資料來源、公開教學對照、模型檢查與真人專業簽核各自記錄，手腳對位及紅橘肌群標色繼續保留。

## 在哪裡查看

1. 進入 3D 示範，在教學面板展開「公開教學對照」。
2. 或開啟文字指南，找到同一個動作，展開相同標題的區塊。
3. 先看它是同類器材教學、局部操作、相關變式、器材資料或課程形式，再讀「這次核對」與「未涵蓋」。來源連結會開啟原始資料。

文字指南直接產生 HTML，不必載入人物模型就能閱讀；來源與遊戲教學面板共用同一份資料。摺疊內容保留鍵盤操作，文字與點擊範圍也有手機版樣式。

## 來源分類的意思

目前 65 項活動各有一份公開來源對照紀錄，合計 55 個不重複來源網址。以下分類描述資料能支持的範圍，沒有表示 65 項動畫全部通過驗收。

| 類型 | 活動數 | 能支持的範圍 | 仍需分開確認的內容 |
| --- | --- | --- | --- |
| 同類器材動作教學 | 42 | 原文確實說明相同或相容器材的站位、主動作或受控回程；不保證相同品牌型號。 | 每段來源實際涵蓋哪些階段；遊戲的取放、關節姿勢與碰撞是否符合。 |
| 局部操作參考 | 2 | 來源明確支持部分器材設定或操作。 | 沒有說明的主動作、回程或進出流程。 |
| 相關變式參考 | 11 | 可以參考部分動作原則，但站姿、支撐、握把、拉力方向或機型有差異。 | 不同的就位方式、手腳接點與運動行程。 |
| 器材資料 | 4 | 產品規格、機構用途、配件或搭設資訊。 | 完整身體動作、安全解鎖、上下機與放回流程。 |
| 課程形式參考 | 6 | 課程類型、基礎原則或部分動作。 | 遊戲整堂課的每個動作、銜接、編排與訓練量。 |
| 尚待核對來源 | 0 | 還沒有可支撐目前標示範圍的來源紀錄。 | 取得來源並實際讀取後，才能更新分類。 |

「回程」通常指一次動作中慢慢回到起點；不等同放回啞鈴、回掛槓鈴、下機或離場。來源沒有說明的部分會保留缺口，不自行補成已驗證的步驟。

## 這次找到的來源差異

| 動作或器材 | 實際讀到的內容 | 處理方式與限制 |
| --- | --- | --- |
| 啞鈴側平舉 | 原先的 [ACE 354](https://www.acefitness.org/resources/everyone/exercise-library/354/single-arm-lateral-raise/) 是腰高滑輪；[ACE 26](https://www.acefitness.org/resources/everyone/exercise-library/26/lateral-raise/) 才是雙啞鈴版本。 | 使用同器材來源，不把滑輪高度與拉力方向套成啞鈴教學。 |
| 平板啞鈴臥推 | 原先的 [ACE 綜合文章](https://www.acefitness.org/resources/everyone/blog/3714/beginner-strength-training-workout/) 確實有持鈴坐下、慢慢後躺及啞鈴臥推；[動作資料庫](https://www.acefitness.org/resources/everyone/exercise-library/19/chest-press/) 則有較完整的握持與主動作教學。 | 綜合文章保留為概略就位參考；大腿承鈴、獨自帶鈴坐起和歸架仍缺精確示範，不能因此宣稱整段過場通過。 |
| 單手啞鈴划船 | [ACE 教學](https://www.acefitness.org/resources/everyone/exercise-library/126/single-arm-row/) 讓一手與同側膝蓋支撐椅面；遊戲採一手扶椅、雙腳落地。 | 保留站姿支撐變式標籤，分開看待上肢划船原則與下肢就位。 |
| 滑輪直桿／EZ 桿彎舉 | 原先的 [ACE 322](https://www.acefitness.org/resources/everyone/exercise-library/322/standing-bicep-curl/) 使用腳踩彈力帶；另找到 [Gold’s Gym 滑輪教學](https://goldsgymbc.ca/wp-content/uploads/2023/09/GGBC-4-Day-Machine-Focused.pdf)。 | 依有讀到的器材與握法更新來源；沒有明述 EZ 桿的內容仍只能列變式參考。 |
| 站姿 V 把划船與低滑輪側平舉 | 原來源分別是坐姿划船與腰高滑輪側平舉。 | 繼續標出站姿或高度差異，沒有把相近的主動作當作整套就位相同。 |
| 史密斯深蹲 | [垂直史密斯產品頁](https://www.lifefitness.com/en-gb/catalog/strength-training/plate-loaded/plate-loaded-vertical-smith-machine) 能確認導軌形式；[Cybex 操作手冊](https://kb.cybexintl.com/Assembly_Manuals/Strength/Cybex_ION_AI_CI-SM_Smith_Rack_1015904-0001.pdf) 另說明安全止擋、抬槓旋轉解鎖與回掛確認。 | 手冊是另一機型，只採相容安全原則；掛鉤旋轉方向、站位及腳位仍依實機調整。 |
| 下胸推機 | 查到的原廠 IL-DCP 是坐姿固定機型，遊戲是下斜躺椅式自製模型。 | 保留機型差異，不能用坐姿手冊驗證躺姿的入位、固定與離開。 |
| 團體課程 | 課型介紹、原則與部分動作有公開資料；七課合計 47 種課內動作、159 段。 | 沒有因讀過課程目錄就宣稱整堂課逐動作已查核。空中瑜珈的設備 FAQ 也不能驗證進布、倒掛及退出。 |

直臂下拉另外確認了動畫問題：原本的手部軌道讓正式模型手肘明顯彎曲，與[來源要求手臂伸長的肩關節下拉](https://www.catalystathletics.com/exercise/907/Straight-Arm-Pulldown/)不符。本次依固定骨長調整軌道，模型肩－肘－腕夾角約為 165°；這是角色設定，沒有把它當作所有人的建議角度。

這次修正範圍是手肘彎曲與握持路徑；仍保留原先的肩部展示角度與站位，沒有延伸至來源描述的身前終點，也沒有宣稱整個動作的完整行程已符合來源。

五種有效滑輪高度的正式 GLB 取樣各涵蓋 619 個循環及進出畫格，合計 3,095 個，手部進入實體握桿金屬的最大深度約 0.645 mm，低於沿用的 1 mm 容差。其餘 24 個 rig 動作另有 360 個畫格對照，取樣結果相同。這些是固定模型與有限取樣的檢查，沒有沿用 0.19 的舊結果代替本次修正驗證，也沒有藉此宣稱連續時間零穿模或真人人體工學通過。

## 仍保留的動作與機構缺口

| 項目 | 目前缺口 |
| --- | --- |
| 啞鈴臥推拿放、肩推翻鈴 | 自製過場還需要更精確的示範依據與慢放檢查。公開主動作教學不一定包含承鈴、持重起坐或翻鈴。 |
| 自由槓臥推出槓與回架 | NASM 頁面主要說明臥推主動作，沒有完整涵蓋出槓、回架確認與離椅。 |
| 斜軌槓片腿推 | 遊戲的鎖定、釋放與停靠機構仍需配合相同類型手冊補齊；不能照搬不同機構腿推機的解扣步驟。 |
| 橢圓機下機 | 目前缺少實體固定扶手及其接點，離場順序也尚未符合握固定扶手、踏板歸低、落地後放手的完整流程。只改手部目標會形成握空氣，必須一併處理模型與路徑。 |
| 臀推固定方式 | 目前的壓墊機臂與參考手冊的腰帶固定機型不同，放開與離開不能當作同型號已驗證。 |
| 伸展與活動度變式 | 椅上臀部伸展、站姿胸肩伸展與站姿胸椎旋轉仍有支撐或手臂位置差異。 |
| 個人體型與活動度 | 固定模型的蹲深、握距、手肘角度及器材尺寸是展示設定，沒有個別人體工學適配。 |
| 實體手機與其他顯示卡 | 尚未取得 iPhone、Android、iPad 與更多顯示卡的實際流暢度、發熱、耗電及觸控延遲結果。 |

## 資料與驗證範圍

逐項對照資料在 [teaching-reference-data-v020.js](../src/teaching-reference-data-v020.js)，畫面與靜態指南共用 [teaching-references-v020.js](../src/teaching-references-v020.js)。原始研究保留在三份 JSON：

- [自由重量與槓鈴](research/public-teaching-free-weights-v020.json)
- [器械與有氧](research/public-teaching-machines-v020.json)
- [滑輪、伸展與團課](research/public-teaching-cable-stretch-classes-v020.json)

核對方式以開啟第一方教學文字、逐字稿及原廠手冊為主，搭配程式定義確認明確差異；沒有下載或匯入網路示範影片。文章描述、產品規格、程式幾何、逐影格看圖與真人簽核的證據範圍各自保留。

靜態產生檢查完成九個文字頁、65 張動作卡與 65 個預設收合的公開教學對照區塊；每個活動 ID 唯一，About 頁也沿用相同來源統計。這項是 HTML 與資料整合檢查，實際 WebGL 動作另行驗收。

0.20 最終來源完成 344 項 Node 測試及一般、GitHub Pages、手機區網靜態版三種建置。六種彎舉也重新完成 3,996 個正式模型姿勢的回歸檢查，未沿用因共用滑輪原始碼變動而失效的舊雜湊；0.19 歷史報告保留。匯出 JSON 與離線 HTML 現在會附上公開教學分類與缺口，仍不會自動建立人員意見或專業簽核。

實際看圖時也發現既有工作台問題：迴圈姿勢預覽會被下一幀蓋回原來姿勢。這次改成持續保留選定位置，關閉後再還原原本播放進度；五項新增測試涵蓋多次更新、切換進出段、還原、繼續播放及退出。圖片驗收另外比對 0% 與 50% 的正面、側面及背面，避免只看百分比就誤認為角色已換姿勢。

最後本機瀏覽器三項實測通過：一般器材的來源與工作台、直臂下拉正常進出及三位置三方向預覽、390px 手機觸控閱讀。九張正式模型預覽已逐張看圖，最後通過版本的圖片與所看圖片逐位元組相同。實際渲染器為 Intel UHD 630／ANGLE Direct3D11；手機案例是桌機 Chromium 觸控模擬，沒有當作實體手機或新的效能測量。來源段落至少 16px，摘要點擊高度至少 44px。

紅色表示主要肌群，橘色表示輔助或穩定參與；伸展與活動度另標目標部位。這些分類沒有量到即時肌肉出力，也沒有從產品列出的肌群自行推算出力比例。

0.19 的 324 項 Node、20 項原生瀏覽器整合、兩項拖曳複驗、三種建置及效能結果都保留在[當版驗收摘要](release-v019.md)。其中 Intel UHD 630 手機能力模擬的一般負載 p95 為 13.5ms，是當版的歷史測量；本次來源整理沒有產生新的效能比較，也沒有把手機模擬當作真機結果。
