# 肩推與杯式深蹲的節奏接入驗證

0.15 將實際肩推及徒手深蹲的量測節奏，接到原有啞鈴肩推與杯式深蹲的姿勢路徑。每個動作交替使用兩段重複；動捕提供的是時間變化，不是直接替換全身骨架、手指或器材接點。原始深蹲沒有負重，不能說成拍攝了持啞鈴的杯式深蹲。

## 路徑對照

以目前程式輸出的 effort，反解封存 0.14 中實際的平滑步進曲線，再取舊路徑上相同 effort 的姿勢。舊曲線上升段為 `smoothstep(phase / 0.44)`，下降段為 `1 - smoothstep((phase - 0.44) / 0.56)`。工具以 60 輪二分反解，並比對上下兩段的完整輸入姿勢與實體器材矩陣，沒有只看手部位置就假設其他部位相同。

兩動作各兩次重複、每次 101 個相位，共 404 個運動姿勢；另外各取 101 個就位與 101 個離場姿勢，共 404 個進出姿勢。808 個姿勢均比對骨矩陣、骨頭比例、接點、手腕方向與實際皮點。最大數值差約 `3.09e-14`，低於原定 `1e-9`。

兩段節奏確實不同：相同相位的最大 effort 差，肩推約 0.383、深蹲約 0.173。這是節奏曲線差，並非出力或肌電量測。

## 直接幾何檢查

同一組 808 姿勢也直接檢查目前程式的身體、自身及表面碰撞、手腳接點與固定骨長；沒有發現禁止的碰撞旗標。全身採 stride 24，累計 1,114,232 個皮點；雙手另外取 stride 1，累計 2,926,576 個皮點，對照實際啞鈴握桿、套環及槓片。

最大接點誤差約 0.670 mm，骨長誤差低於 0.0002 mm；手部入金屬最深約 0.365 mm，仍保留既有 1 mm 數值容差，沒有宣稱完全零穿入。這些是有限姿勢與幾何取樣，不是人體工學、連續碰撞或真人教練的專業簽核。
