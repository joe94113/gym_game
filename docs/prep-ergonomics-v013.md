# 器材準備動作修正：0.13

這輪先檢查拿鈴、搬運、入座、上機、握持、放回與離開。使用正式真人 GLB 和現有器材，保留固定骨長、掌心／鞋底目標與紅橘標色。人體工學的教學適用性仍需真人教練審查；這裡記錄已定位的動畫錯誤與修正，沒有把腕角大小直接當成傷害判定。

## 已定位並修正

- **提踵等機台的空手路徑跳接。** 原本 `free=true` 不只放開握把，還把整隻手改成新算的放鬆姿勢。提踵準備在腳步切換的邊界，掌心會突然移動約 47 公分。現在保留兩端原有手部路徑，只解除握持；側向走道的手部方向也先轉回人物真正的局部座標求解。
- **划船測功儀跨中梁時膝蓋翻轉。** 原路點讓腳踝繞到髖部後方，同時換膝蓋彎曲方向，造成幾個畫格內繞軸旋轉。現在腳先從髖部前方抬過中梁，再落到走道。沒有拉長腿來碰踏板。
- **側向跨架看起來像蛙腿橫移。** 第一次看三向圖時，腿推和腿伸展雖然通過碰撞檢查，人物仍面向器材、兩膝向兩邊張開跨架。現在先用交替小步轉向，再朝步行方向跨過側框。轉身腳距收窄，第一步讓髖部留在支撐腳附近，避免支撐腿接近伸直時膝蓋突然偏轉。腿推另走斜線，依序避開座墊、前方載重片與後方儲存槓片。早先接近相反方向的膝部彎曲向量也改用局部連續角度插值，避免接近零向量時翻轉。
- **長準備流程被壓得過快。** 提踵原本約 10.15 秒的分段被共用的 6.2 秒壓縮；腿伸展、腿彎舉與坐姿划船也有同樣情況。現在各用足夠的進出時間，走動的起步與停步增加緩衝。
- **轉身時雙腳滑地。** 輔助引體／雙槓、髖內外展與背伸展改成左右腳交替的小步轉身。踩地的鞋子保留在器材座標內，只有移動中的腳抬起再落下；背伸展與輔助機的轉身也留出較長時間。
- **髖機坐下時抬肘、拖腳。** 三向圖抓到既有準備姿勢把雙肘抬到接近肩高，手卻留在腰邊。空手改為自然放在大腿前方，依真正的手掌方向和固定骨長內插手臂；移向握把時保持在腿墊上方。轉身後先退半步踩穩，再固定雙腳坐下，替換原本邊坐邊拖動鞋子的直線過渡。自由走動的手掌方向也跟著擺手重新計算。
- **腳踏車與哈克的換腳速度折角。** 進一步檢查較高的速度診斷，抓到原本正弦抬腳在離地／落地端點仍有垂直速度。這兩型的步行段改用平滑相位再取正弦，保留路點、最高抬腳高度和時長。這次只修兩型的步行抬腳，沒有靠整段減速讓數值變小。
- **新器材設定的準備路徑。** 提踵外繞道由 1.30 公尺移到 1.55 公尺，避開新增的小槓片；橫移改為真正踏步。腿伸展入座時，過渡足位往前調到 0.38 公尺，讓大腿留在小腿滾筒上方，再把小腿放入，兼容升高的座墊。肩推新增從握把前方伸手、再抬肘握住的中繼姿勢，避開升高座墊後上臂會掃過的後方連桿。

沒有為了把杯式托鈴的 42° 腕部延伸變成較小數字，就強迫掌心改成不適合托住啞鈴的方向。杯式握法保留；其餘七種啞鈴已另外校正逐指彎曲、拇指對掌及掌心接觸位置。這是有意的手部變動，不能再宣稱整隻手與 0.12 完全相同，教學適用性仍留待真人教練審查。

## 驗證方式

`scripts/audit-preparation-v013.mjs` 對八種啞鈴及 32 種機台的進、出流程逐相位量測。`--before` 只載入封存的 `.local-tools/v013-before`，不借用更新中的現版程式。正式使用 1,001 相位，避免粗取樣跨過一整個腳步，誤把兩次種腳當成鞋子滑動。

數值比較使用同一份碰撞量測器與不解碼貼圖的 GLB 載入器；它們以獨立的 `validatorSourceHashes` 記錄，不冒充成舊版遊戲來源。真正的前後版動畫、器材與其本地相依模組由 import 閉包各自收集，在載入前及量測結束核對 SHA。來源或量測器途中改變會使結果失敗。

量測包含真實骨架的接點、骨長、膝與肘的位置變化、地面種腳、肢段對器材及自身的碰撞。地面種腳的水平移動只比較前後都在地面兩毫米內的樣本；隨踏板移動的支撐腳與抬腳不當作滑地。動畫速度是定位跳接的數值，沒有宣稱為人體的通用安全上限。

八個[回歸測試](../tests/preparation-v013.test.mjs)涵蓋提踵手部接縫、划船與腿推膝部翻轉、跨架時的轉身與膝部方向、髖機低肘及入座種腳、新座高與多片槓片的窄相位、交替轉身的種腳，以及真人動捕走跑手臂混合的 1,629 個姿勢之骨長、可達性與自身碰撞。新增器材設定另由設定模組檢查組合及蒙皮表面。

[正式 CPU 比較](../artifacts/preparation-v013/comparison.json)已重新完成每版 80,080 個姿勢，新版 40 案例的可達、骨長、種腳、肢段及自身碰撞檢查通過，來源及量測器起訖 SHA 穩定。首輪數值通過後，三向圖又抓到上述側向跨架和髖機姿勢問題，因此進行第二輪修正與真正重跑；首輪圖片和失敗的 AI 觀察記錄保留在 `artifacts/preparation-v013/visual/initial-agent-review/`。舊版五種轉身的種腳檢查失敗也如實保留。

新設定另完成 152 配置的 15,352 個運動姿勢與 30,704 個完整進出姿勢，包含座高、握距端點及較多小槓片；肢段、自身與取樣皮面未出現禁止碰撞。八項回歸的實際子程序、來源與 TAP 雜湊另存 [unit-receipt.json](../artifacts/preparation-v013/unit-receipt.json)。

手掌、肘與腕因新握法而有意改動，另以 [16,372 個真 GLB 握持與拿放姿勢](../artifacts/dumbbell-fingers-v013/qualification.json)檢查，包含八種預設動作、30°／45° 臥推、密集的握穩／放手區間、段界與全部手部皮點對硬桿／套環／槓片。最大入金屬深度約 0.365 mm，低於列明的 1 mm 容許值；不能把這個容許值稱為完全零誤差或每根手指都已量到接觸力。

有限姿勢取樣、代理碰撞和靜態圖片無法證明所有可能姿勢完全無穿插，也不等同逐指受力、關節負荷或真人教練的完整連續動作簽核。
