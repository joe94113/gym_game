## 效能怎麼回傳

先進入同一場景，等模型、聲音和器材就位完成。到「操作說明 → 效能檢測」選固定畫質，再開始 20 秒紀錄，照固定路線走動，或播放指定器材／團課，完成後下載 JSON。以相同起點、視角、路線和畫質至少重複，保留所有結果；自動畫質若降解析度，分開列出實際 framebuffer 和陰影狀態。

另做 10 分鐘持續遊玩，前後各保留 20 秒紀錄，記下是否充電、是否低耗電模式、螢幕亮度及環境條件；發熱先記觀察，沒有儀器就不填溫度。記憶體無法從該瀏覽器可靠讀取時也填 pending。紀錄平均、p95／p99、最大幀間隔、超過 50ms 比例、實際渲染設定和中斷情形，不把模擬器或桌面 GPU 當成手機。

JSON 的逐幀資料來自遊戲 RAF 間隔，包含排程與較長畫格，並非 GPU 單獨執行時間或每張畫面確實呈現的保證。觸控版降低像素、陰影和初始抗鋸齒負載，前後比較必須列明這些畫面取捨。
