# 顯示卡測試與回傳方式

本機目前只有 **Intel UHD Graphics 630**。沒有把同一張顯示卡的不同 ANGLE 後端，或 SwiftShader 軟體繪圖，算成其他顯示卡。

| 實際環境 | 目前狀態 | 範圍 |
| --- | --- | --- |
| Intel UHD 630、Windows、原生 Chromium／D3D11 | 本輪實測環境 | 固定畫質的走動、奔跑、導航與啞鈴示範；完整動作與網頁回歸另有報告 |
| SwiftShader 軟體繪圖 | 作相容性抽查 | 不代表另一張實體顯示卡，也不用於實體 GPU 前後效能數字 |
| NVIDIA、AMD 獨立顯示卡 | 尚未取得實機結果 | 可透過下列網頁工具匯出資料 |
| Apple Silicon／其他 Intel | 尚未取得實機結果 | 可透過下列網頁工具匯出資料 |

硬體清單見 [hardware-inventory.json](../artifacts/performance-v015/hardware-inventory.json)。Windows 回報的 AdapterRAM 不一定代表整合顯示晶片可用的完整共用記憶體，不以它當作效能分級。

## 在另一台電腦測量

1. 開啟同一版本的遊戲，先進入自由走動，或選好要測的器材，等載入與就位完成。
2. 到「操作說明」選 **流暢優先**，保持視窗大小、視角與起點固定。點「開始 20 秒測量」，照平常走動或播放動作；不要切換分頁。
3. 完成後再開「操作說明 → 效能檢測」，下載效能紀錄 JSON。檔案包含顯示卡／瀏覽器、實際 framebuffer、畫質、位置與活動，以及逐幀間隔。
4. 在相同起點、視角、路線與畫質再測一次；再改 **畫面細節** 重複。比較其他電腦時也保持相同條件。

這是手動遊玩紀錄，不能把不同路線或畫質的結果直接當作顯示卡排名。自動畫質若改變解析度或陰影，檔案會標示 `fixedQuality:false`；視窗或分頁離開前景時會中斷。資料只存在本次網頁記憶體，需自己下載，不會自動上傳或讀取訓練日誌、帳號、審查人的姓名。

平均、p95、p99、最大幀間隔及超過 50 ms 比例從實際遊戲 RAF 間隔計算，包含較長畫格，不刪掉 250 ms 以上的停頓。第一個跨越開始按鈕的間隔會略過。這不是 GPU 執行時間，也不能保證每次 RAF 都有一張畫面確實呈現在螢幕。

正式前後比較另使用自動化相同路線、固定視窗與畫質，避免用手動紀錄取代可控制的比較。真人教練審查工具、幾何檢查或這張測試表，都不代表已取得其他顯示卡的實機結果。
