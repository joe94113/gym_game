# 0.10 個人化安排的分段探索

「伸展與活動度」的十五分鐘安排有六個步驟：腳踏車暖身、四個活動與伸展、再回腳踏車緩和。0.9 的導航用動作 ID 去重，同一台腳踏車只保留一次，完成最後一個伸展後便提前顯示探索完成；說明也只會找到腳踏車的暖身處方。

本版另用步驟編號、段落與活動 ID 建立探索步驟。每個步驟保存自己的說明與已看過狀態，同一器材可在不同段落再次出現。路線會回到腳踏車緩和，教學側欄顯示目前的段落及處方。點選步驟只改導航，不會順便標記已完成；取消、關閉教學或查看無關動作也不推進路線。

「已了解」仍是動作學習，沒有把人物示範當成玩家實際運動。六個步驟看完時，全域動作學習只增加五個不重複動作；重看或重新探索不會重複灌入學習數量，也不會自動增加重量。一般部位推薦與自由探索繼續使用原有流程。

路線狀態只存在本次探索，重新開始或採用新安排會清空步驟進度；瀏覽器內原有的動作學習與訓練偏好保留。側欄字級調為十四像素，段落說明可展開，完整清單可捲動。

純函式在 `src/training-route.js`，介面整合在 `src/trial-ui.js`。`tests/training-route.test.mjs` 的五項檢查涵蓋同器材重訪、完整走回緩和、無關動作、跳選與回看，以及新安排不沿用舊步驟；`tests/training-route.spec.js` 另用正式網頁驗證六步路線、學習數量、取消、無關動作、跳選緩和和重新探索。這些測試只確認遊戲路線及學習記錄，不證明玩家有實際完成運動。
