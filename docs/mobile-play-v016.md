# 手機試玩與操作

肌動基地可用手機觸控探索。先選今天想練的部位，再按開始；想自己逛場館，就選自由走動。人物、器材動作、手腳接點和紅橘標色與電腦版共用。

| 想做什麼 | 怎麼操作 |
| --- | --- |
| 走動 | 按住左下「移動」搖桿拖曳，放手就停止；拖遠一些會走快一點 |
| 奔跑 | 移動時，另一指按住右下「按住奔跑」；放開後恢復走路 |
| 轉動視角 | 在場景空白處單指拖曳 |
| 拉近或拉遠 | 在場景上雙指縮放 |
| 使用器材或設施 | 走近後，按右下「使用／選動作」或「使用設施」；有人正在用時，對方會先退讓 |
| 看教學和器材設定 | 示範開始後，點「展開教學」，上下捲動查看內容；收合後仍可暫停和切換播放速度 |
| 放回與離開 | 按右下「返回探索」，等人物放回器材並離場 |
| 找器材 | 「功能選單 → 地圖」，點地圖編號或下方文字站點；也可開啟動作清單 |
| 訓練安排、日誌和畫質 | 開啟上方「功能選單」選擇功能；畫質在「操作說明」內 |

使用器材時會隱藏移動與奔跑按鈕，留下返回探索；開啟選單、視窗或輸入表單時會停止移動。切到別的分頁、旋轉螢幕或觸控中斷，也會清除按住狀態，回來後重新操作即可。

直向時，教學位於畫面下方，底部留給觸控按鈕。較矮的橫向畫面改在右側顯示教學；可先收合，留更多空間看人物動作。選單、日誌和教學內容都可上下捲動，操作目標至少 44px。

## 畫質與資料

手機預設使用較低的像素預算，並關閉動態陰影。若持續出現慢幀，自動畫質可再降低解析度；也能在「操作說明」手動選「流暢優先」或「畫面細節」。調整影響解析度和陰影，人物動作、器材接點及紅橘標色保留，完整預算見[手機渲染設定](mobile-rendering-v016.md)。

GitHub Pages 版把日誌、學習進度與訓練安排存在目前瀏覽器。手機與電腦不會自動同步；更換裝置或清除網站資料前，請在日誌匯出 JSON 備份，再到另一台裝置匯入。

目前尚未取得 iPhone、Android 或 iPad 真機結果，長時間流暢度、發熱、耗電和手機瀏覽器中斷恢復均列為 pending。瀏覽器模擬只能檢查操作與版面，真機待測範圍見[手機測試表](mobile-test-matrix-v016.md)。

## 用手機開啟本機版本

正式 GitHub Pages 網址尚未公開部署時，可讓手機與開發電腦連同一個區域網路，在電腦執行：

```powershell
npm.cmd run preview:mobile
```

指令會先建置本機日誌模式到 `.local-tools/mobile-v016-preview`，再於 `0.0.0.0:5175` 提供靜態試玩。它只服務建置檔，`/api` 回傳 404，沒有帳號 API；不填正式 canonical，並使用 noindex。這不會修改 GitHub Pages 的正式網址。

手機開啟終端機顯示的區網網址。本次開發電腦為 `http://192.168.114.55:5175/`，IP 可能隨網路改變，之後以終端機顯示為準。`127.0.0.1` 指的是裝置自己，不能從手機連到另一台電腦。若連線失敗，確認兩台裝置在同一網路，以及電腦防火牆是否允許這次靜態試玩服務；不必將服務公開到網際網路。
