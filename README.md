## 既有功能與 0.12 歷史效能

0.12 減少人物重複骨架計算、視野外電視與閒置 InBody 的重畫，以及同一次導航搜尋的重複查詢。當時場館格局、人物細節、動作、手腳對位與紅橘肌群標色保留。固定畫質、實體 Intel UHD 630 的兩輪遊玩比較中，八種情境的平均畫面間隔均下降；流暢模式約改善 2～10%，畫面細節模式約 8～15%。多數情境的第 95 百分位仍接近原本，部分超過 50 ms 的畫格比例變差，完整條件與限制見[0.12 歷史效能比較](docs/performance-v012.md)。這些不是 0.13 的 FPS 或改善幅度。

啞鈴臥推的椅背現在可選 0～45°，每次調整 1°。打開「器材設定」，用滑桿或選單挑角度，按「套用」後，人物會放回啞鈴、調整椅背再重新就位；按 Esc 可取消待套用設定。0.11 也修正了平躺臥推入座時的座墊懸空，詳見[角度、支撐與接觸容差](docs/bench-angle-range-v011.md)。

龍門架新增繩索槌式彎舉、直桿直臂下拉、站姿繩索捲腹，各自配置滑輪高度、握把、取放托架、進出路徑及紅橘肌群，詳見[新增滑輪動作](docs/cable-actions-v011.md)。教室、浴室離開視野且休眠滿 12 秒後，會釋放房間獨占的 GPU 資源；返回時重新上傳。CPU 模型與共用人物仍保留，詳見[資源管理範圍](docs/room-gpu-resources-v011.md)。0.11 的實體 Intel UHD 630 [前後測量](docs/performance-v011.md)確認閒置資源下降；當時沒有測得穩定畫面時間改善。

0.10 修正了啞鈴拿起、搬運、入座、後躺與放回的手腕／肘部動作，實體啞鈴握桿會跟著前臂轉向；當時原八種運動循環、椅背設定與紅橘標色保留。見[歷史動作修正與檢查限制](docs/dumbbell-ergonomics-v010.md)。本版七種握桿動作的手部變動另由上述 0.13 報告驗證。

遠處會員改用兩級索引簡化模型，每人三角形由 56,185 降至 42,369／35,847；玩家、近處、交接與團課仍用完整模型，選配資料下載失敗也會保留原真人。見[人物細節管理](docs/npc-geometry-lod-v010.md)。個人化探索另修正暖身、緩和使用同台器材時被去重的問題；十五分鐘伸展路線有六個步驟，五個不重複的學習動作，見[分段探索](docs/training-route-v010.md)。

新增教室與浴室分區休眠、跨器材重複零件批次繪製，格局、碰撞與動作接點保留。流暢模式在房間內會使用較適合稀疏視角的原繪製，回到主場館恢復批次；0.11 起另釋放房間獨占 GPU 資源，CPU 模型仍常駐。早期測量條件與前後原始數字見 [效能紀錄](docs/performance-v09.md)。

啞鈴臥推可選 0～45°；三頭下壓可選繩索或新增的直桿，其他相容握把可切換對應動作。打開教學側欄的「器材設定」操作，更換時會先收回、離開，再重新就位。上方「訓練安排」提供目標、經驗、時間、部位及主動回報的調整，組數與休息是建議，學習進度不算實際運動紀錄。見 [器材設定](docs/equipment-settings-v09.md)與[訓練安排](docs/training-plan-v09.md)。

場館擴為 64 × 61 公尺，自由重量區約 500 平方公尺。自由重量、固定器材、槓片、有氧、草皮、櫃台、團體教室和淋浴休息設施各有地面顏色、標線與招牌；地圖和實際場景共用同一份配置。

人物使用具有骨架、蒙皮、皮膚與衣物貼圖的真人比例 GLB。普通器材與動作庫共用同一套活動介面；普通器材按 E 會開始示範，啞鈴、草皮和龍門架則先選動作。

選好後，人物會走到器材旁、轉身、入座或踩穩支撐，再握住器材開始。結束時先回到安全位置、放回啞鈴或槓鈴、鬆手，再起身走回走道。浴室、測量台與團課也有各自的進出路徑。

動作清單共 73 項：58 種器材與地面動作、7 種團課，以及 8 項其他設施。場館仍有 56 個器材／設施互動點、46 台器材，其中 18 台為有氧器材。相同有氧器材共用學習進度。

- 啞鈴區有 8 個動作：彎舉、槌式彎舉、肩推、側平舉、單手划船、臥推、杯式深蹲及羅馬尼亞硬舉。
- 草皮區有 6 個動作：髖屈肌、腿後側、臀部、胸肩、小腿伸展，以及胸椎轉動。
- 龍門架提供繩索、D 形手把、直桿、EZ 桿、V 把和腳踝帶的相容動作。握把由動作決定，同時設定滑輪與接點。
- 場內有 46 台器材，其中 18 台有氧器材排成三列，包含跑步機、腳踏車、橢圓機、划船測功儀和階梯機。相同器材共用動作。
- 補上引體／雙槓輔助機、髖外展與內收機、背伸展椅、牧師椅，以及槓片式平躺胸推和下斜胸推。原有槓片式上斜胸推與腿推保留；蝴蝶機可選夾胸或反向飛鳥。
- 紅色表示主要肌群，橘色表示輔助參與。伸展時改稱「伸展目標」和「支撐參與」；團課的人物與面板肌群圖會隨段落更新，標色可以關閉。
- 可轉動視角、縮放、暫停、慢放和拖曳行程滑桿。學習進度按動作保存在這個瀏覽器。
- 場內有使用不同器材的其他會員。接手有人使用的器材時，會員會先放回器材、鬆手、移到走道，才交給玩家。
- 更衣區有兩間廁所、兩間獨立淋浴間、乾式烤箱、蒸氣室和冷水池。設施可按 E 使用，門、水流、蒸氣與水面會隨互動更新。人物保留運動服。
- 入口有接待櫃台，場內另有教練服務櫃台、諮詢座位、九座獎盃與 16 位虛構教練的介紹牆。大頭照使用場景原創圖像，沒有挪用真實教練的照片或姓名。
- 櫃台旁的 InBody 分析儀可示範站位、握持和掃描進度，完成後顯示明確標示的固定範例，沒有量測玩家的身體資料。
- 團體教室提供全身活動、有氧舞蹈、飛輪、TRX 懸吊、槓鈴肌力、空中瑜珈與墊上皮拉提斯。靠近按 E，或點上方「團體課程」選課；教練與學員會先換好器材再跟課。畫面顯示已過／剩餘時間、當前與下一段、節奏或趟數，保留暫停、慢速、段落預覽與紅橘肌群標色。
- 牆面有三張台灣風格的原創健身廣告和三台持續播放原創運動動畫的電視。電視不是實際體育頻道直播。

逐項功能核對與尚未完成的部分，見 [docs/feature-audit.md](docs/feature-audit.md)。

七課共 159 段。全身活動課為 15 分鐘（暖身、活動、緩和各五分鐘），其他六課各 30 分鐘（五分鐘暖身、20 分鐘主訓、五分鐘緩和）。每課有不同動作、節奏、輪次與恢復，走到終點就停下並顯示摘要，不會循環重播。槓鈴組間會放槓、鬆手休息，再拿起；空中瑜珈包含地面活動、離地坐姿與受支撐倒掛。

跳段或拖曳會切成預覽，結尾明示「預覽已到課程結尾」，不當成完整上課；「已了解」只保存動作學習。這些是遊戲原創課表，沒有冒稱真人教練已審核。課表與官方參考資料見 [課程設計](docs/course-design.md)。

0.8.0 加上原創團課背景音樂和中文預錄口令。就位後先倒數三秒；換段前八秒提醒下一個動作，每段最後三秒倒數，包含休息與課程結尾。「音樂與教練口令」可以分別調音量或關閉，設定保存在瀏覽器。暫停、跳段、換課和離開會清掉舊聲音，不追播漏掉的口令。

Shift 現在會切換成跑步動作，速度由每秒 1.8 公尺漸升至 4.2 公尺。說明正文放大為 14～15 px，教學側欄也加寬。操作說明內新增「自動調整／流暢優先／畫面細節」三種畫質設定；自動模式遇到軟體顯示或持續較慢的畫格會降低負載。遠處會員降低姿勢更新頻率，交接和走動維持逐畫格更新。

啞鈴拿取、搬運與臥推準備，以及自由槓／史密斯深蹲的入架、出架、回架，改用各自的分段路徑。相關數值與三向畫面以 [功能核對](docs/feature-audit.md) 的本版證據為準。

## 啟動

需要 Node.js 22.12 以上。

```powershell
npm.cmd install
npm.cmd run dev
```

瀏覽器開啟終端機顯示的本機網址。建置用 `npm.cmd run build`，預覽用 `npm.cmd run preview`。遊戲需要 WebGL。

| 操作 | 電腦 | 手機觸控 |
| --- | --- | --- |
| 走動 | WASD／方向鍵 | 按住左下搖桿拖曳 |
| 奔跑 | 按住 Shift，再移動 | 移動時，另一指按住「按住奔跑」 |
| 轉動視角 | 按住場景空白處拖曳 | 在場景空白處單指拖曳 |
| 拉近／拉遠 | 滑鼠滾輪 | 在場景上雙指縮放 |
| 使用器材／設施 | 靠近後按 E | 靠近後按右下「使用／選動作」或「使用設施」 |
| 場館地圖 | M | 「功能選單 → 地圖」，也可點文字站點導航 |
| 離開示範 | Esc | 右下「返回探索」，會先放回器材再離開 |
| 展開教學 | 教學側欄 | 點「展開教學」，可捲動查看與調整器材 |
| 關閉視窗 | Esc 或關閉按鈕 | 視窗右上關閉按鈕 |

手機也能選今天的訓練目標、自由探索和使用訓練日誌。GitHub Pages 版仍保存於目前瀏覽器，換裝置前請先匯出 JSON；觸控操作不會啟用雲端同步。

要從同一區網的手機試玩，可在電腦執行 `npm.cmd run preview:mobile`。指令先建置本機日誌版，再於 5175 埠提供靜態檔；手機使用終端機顯示的區網網址。這個預覽不開放帳號 API，也不設定正式 canonical，詳細方式見[手機試玩說明](docs/mobile-play-v016.md)。

## 動作與碰撞範圍

人物骨長固定，姿勢透過實際骨架旋轉與反向運動學求出。掌心、鞋底與器材接點共用資料，另檢查手臂、腿部、鞋及軀幹對器材的體積碰撞，並抽樣變形後的蒙皮表面。椅墊、地板、握把等合理接觸按部位列明。

這些檢查涵蓋既定動作與進出路徑。人物會實際移動，啞鈴會從架上拿取並歸還；架上槓鈴先回架再放手，團課短槓則放回地面。0.6.0 另校準跑步機擺臂、腿後側伸展、划船測功儀的出力順序，以及提踵、腿推、哈克和有氧踏板的鞋底支撐。鞋面檢查會移除踏板的足部接觸豁免，避免把鞋子穿入踏板當成合理接觸。

0.6.0 原有 55 種動作的 825 個畫格與兩份 AI 圖像抽樣報告保留作基礎證據；舊短團課的 105 個姿勢畫格及七張教室圖只供歷史對照。0.7.0 的 45 種課內動作、159 段全課、四位人物與中途離場另有歷史報告，見 [功能核對](docs/feature-audit.md)。0.13 新增的 CMU 走跑手臂混合、兩種空中動作與準備修正各有自己的驗證，不沿用舊圖宣稱通過。吊布使用有界 PBD，尚無通用全身剛體物理；有限抽樣也不等同真人教練逐格驗收。真人簽核欄位見 [教練審核表](docs/coach-review-checklist.md)。

0.7 的真實手部蒙皮檢查記錄槓鈴握持最大入軸深度 0.675351 mm，低於 1 mm 容許值；換握會先放槓、鬆手再拿起。當時七課全部 152 個內部段界的極近時點取樣也通過銜接檢查，關節與手部表面差均低於 0.5 mm；歷史數值和取樣限制列於功能核對。

學習進度沿用 `form.exercise-progress.v1`，舊器材認識進度 `form.learned` 保留，帳號可同步對應進度。訓練安排依目標、經驗與時間提供參考組數和休息，只有主動回報才調整；日誌另收使用者自行填寫的實際運動，沒有從觀看動畫推算重量或療程。

0.12.0 的 110 項 Node、46 項原生 WebGL 網頁測試與建置全數通過；另有 1 項 SwiftShader 骨架／拿放測試通過，並非整套軟體渲染回歸。22 張前後動作圖片組成 11 組配對，像素完全相同，已實際檢視四張比較圖；遮擋及有限取樣的限制列於[歷史畫面檢視](artifacts/performance-v012/visual/manual-review.json)。八種情境的真實遊戲 RAF 比較見[0.12 效能比較與原始資料](docs/performance-v012.md)，完整歷史證據見[0.12 驗證摘要](artifacts/verification-summary-v0.12.json)。

0.11 的 93 項 Node、44 個原生 WebGL 網頁／碰撞案例及 1 個 SwiftShader 房間釋放／返回測試紀錄，保留於[歷史摘要](artifacts/verification-summary-v0.11.json)；當時完整第一輪為 41 過、3 個舊測試假設失敗，更新選項數與手動時鐘假設後，定點重跑該 3 例通過。0.9 的測量另保留在[歷史效能紀錄](docs/performance-v09.md)與[歷史摘要](artifacts/verification-summary-v0.9.json)。以 `FORM_TEST_RENDERER=native` 可切換測試到原生顯示晶片；預設保留 SwiftShader 測試模式。有限相位與表面取樣無法保證任意姿勢都不會穿模，單機時間測量也不代表所有硬體的 FPS。
